# Lecture teaching model

`/viewer/ios?lecture=1` opens the existing production viewer with two fixed public teaching STL files. `&readonly=1` retains the existing patient-view controls. This mode performs no clinical lookup and ignores supplied study, path, file and share selectors.

The two unbased scans were supplied in the clinical lecture workspace. Their binary metadata headers are neutral, and the geometry is visually checked from multiple directions before release. The name-bearing fabricated base model is excluded. This is a teaching example, not proof of an AI design, a diagnosis or a treatment outcome.

No clinical runtime, authorization or default viewing behavior is changed. The public lecture mode is explicitly selected and its assets are a fixed allowlist.
